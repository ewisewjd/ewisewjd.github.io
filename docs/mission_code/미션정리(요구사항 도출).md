
# 미션 소개

html / css / javascript를 활용하여 외부 라이브러리 없이 반응형 포트폴리오 웹사이트를 제작하라 

- 이 세가지는 브라우저가 이해하는 유일한 언어이며 프레임워크들 즉 react, vue, angular 등도 이 세가지로 변환되어 동작한다. 

  
단순한 화면 설계가 아니라 사용자 이벤트 -> dom 조작 -> 화면 변화가 연결되는 웹의 동작 원리를 결과물로 확인한다. 

- dom이란 무엇인가? 
- 사용자 이벤트란 무엇인가?
- 웹의 동작원리는 어떻게 되는가?

github api를 연동하여 실제 서비스에서 자주 등장하는 로딩/ 에러/ 빈 상태를 직접 처리하는 경험을 쌓습니다. 

-  로딩/에러/ 빈상태는 어떻게 되는것인가?
  
다음 미션인 react 학습의 필수 기반이 됩니다. 
react는 컴포넌트, 상태, 이벤트 개념이 모두 이 미션에서 다루는 don 조작과 이벤트 처리를 추상화 한것이기 때문입니다. 

- 컴포넌트, 상태, 이벤트 개념은 무엇인가?

자바스크립트 기초(dom&이벤트)
- JavaScript 파일을 defer 속성으로 연결한다.
- var 대신 const, let만 사용한다.
- HTML에 onclick 속성을 쓰지 않고, addEventListener로 이벤트를 연결한다.
- DOM 조작:
  - querySelector, querySelectorAll로 요소를 선택한다.
  - textContent, innerHTML로 내용을 변경한다.
  - classList.add, remove, toggle로 클래스를 조작한다.
- 이벤트 처리:
  - click, submit, scroll, input 이벤트를 다룬다.
  - event.preventDefault()로 기본 동작을 방지한다.
  
    - defer 속성은 왜 사용하는가?
    - var 는 왜 사용하지 않으며 const와 let만 사용하는가?
    - html에 onclick 속성은 왜 사용하지 않는가?
    - 반대로 addeventlistener로 이벤트를 연결하는 이유는?
    - dom 조작은 어떻게 하며 옵션은 어떤것들이 있는가?
      - 왜 여기서는 querySelector, querySelectorAll로 요소를 선택하도록 하였는가?
    - 내용조작은 어떻게 하는것이며 textcontent, innerhtml은 각각 무엇이고 왜 사용하는가
    - 클래스를 조작하는 방법은 어떤것이 있으며  classList.add, remove, toggle은 어떤 기능을 하고 각각 왜 사용하는가?
    - 이벤트 처리는 어떻게 하며 click, submit, scroll, input는 무엇인가?

상태 관리 패턴

"사용자 이벤트 → 상태 변경 → 화면 업데이트" 흐름이 명확해야 한다.

다음 3가지 이상의 "상태 → 렌더링" 흐름이 존재해야 한다.

- 예시 1: 다크 모드 토글 → 테마 상태 변경 → 전체 화면 스타일 변경
- 예시 2: API 호출 → 로딩/성공/에러 상태 변경 → Projects 섹션 렌더링 변경
- 예시 3: 폼 입력 → 유효성 상태 변경 → 에러 메시지 표시/숨김
